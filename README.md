# 👗 FashionHub Mobile UI

## 📌 Overview

FashionHub Mobile UI is a modern e-commerce web interface built with Next.js and Tailwind CSS. It provides a responsive and user-friendly shopping experience with a clean design, fast performance, and reusable UI components.

---

## ✨ Features

- 🛍️ Modern Fashion Store Interface
- 📱 Responsive Mobile-First Design
- 🔍 Product Search
- 🏷️ Product Categories
- 🛒 Shopping Cart UI
- 👤 User Authentication Pages
- 🎨 Clean & Modern User Interface
- ⚡ Optimized Performance

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Kalana997/fashionhub-mobile-ui.git
```

Navigate to the project

```bash
cd fashionhub-mobile-ui
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser

```text
http://localhost:3000
```
